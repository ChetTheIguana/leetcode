# LeetCode Practice

A repo for Wulfric to practice LeetCode problems with the help of an AI tutor.

## How it works

Claude acts as a coding tutor using the Socratic method — guiding through hints and questions rather than giving away solutions. The goal is to build real problem-solving skills, not just collect answers.

## Languages

Problems include starter files in:
- **C++** — compile with `g++ -o solution solution.cpp && ./solution`
- **C#** — run with `dotnet run` from the csharp directory
- **Python** — coming soon

## Structure

```
problems/
  001-two-sum/
    README.md          # Problem description, examples, constraints
    cpp/solution.cpp   # C++ starter with test harness
    csharp/Program.cs  # C# starter with test harness
  002-add-two-numbers/
    ...
```

Each problem folder has a README with the full problem statement and starter files with a `main` function that runs the provided examples — just fill in the solution method and run.
